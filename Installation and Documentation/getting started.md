# Installation
Clone the repository and add it to your MATLAB path:
```matlab
git clone https://github.com/Mehnuma/BLeS.git
addpath(genpath('BLeS'))
```

# Direct MATLAB Installation
Please follow the instructions below to install `BLeS` from a MATLAB toolbox installer file.
+ Locate and download the toolbox installer file: `BLeS.mltbx`, in the [Installation and Documentation Folder](https://github.com/Mehnuma/BLeS/tree/main/Installation%20and%20Documentation).
+ By double-clicking this file, a prompt will appear, and the toolbox will be installed by selecting `Install`.
+ The toolbox can be managed by clicking `Add-Ons` > `Manage Add-Ons`.

# Octave Usage
To use the `BLeS` toolbox in `Octave`, please add the [Octave Folder](https://github.com/Mehnuma/BLeS/tree/main/Octave) to the `Octave' working directory on your local machine.
